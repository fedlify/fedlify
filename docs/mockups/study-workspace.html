Site runner helper

Optional local web app at http://127.0.0.1:PORT/#token. Headless sites use the same commands in a terminal. Shown below: the operator's view.

Get runner panel (on the site page, for the kit creator)
  1. Create kit (re-enter your account password). Passphrase shown once: example-maple-river-stone-lamp-cloud (example only).
  2. Send the passphrase by a different channel than the file.
  3. Headless: ./fedlify-runner.sh unlock && ./fedlify-runner.sh start

The passphrase protects the handover and copies at rest. It does not protect against the site's own operator, root on the host, or a compromise of Fedlify.
